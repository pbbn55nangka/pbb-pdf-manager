PBB PDF Manager

Alat dalaman untuk memproses borang permohonan keahlian PBB N55 Nangka.
Internal tool for processing PBB N55 Nangka membership application forms.

Tentang aplikasi ini / About

PBB PDF Manager ialah aplikasi dalaman yang digunakan oleh pengendali cawangan sahaja. Ia membaca e-mel notifikasi borang permohonan keahlian daripada Jotform dalam peti mel pengendali, memproses lampiran PDF, menyimpan borang dalam Google Drive pengendali, dan mengemas kini senarai rekod dalam Google Sheets.

PBB PDF Manager is an internal application used only by the branch operator. It reads Jotform membership-form notification e-mails in the operator's own mailbox, processes the PDF attachments, stores the forms in the operator's Google Drive and updates a tracking list in Google Sheets.

Aplikasi ini tidak dibuka kepada orang awam. / This application is not open to the public.
